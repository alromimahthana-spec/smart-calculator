# 🧠 الحاسبة الذكية - مشروع ثناء الثالث

## ✨ وش يسوي البرنامج؟
حاسبة ذكية تاخذ منك رقمين وتحسب لك كل شي!
والأهم، هي تفكر وتقرر: من الأكبر فيهم!

### ▶️ كيف تشغله؟
1. افتحي ملف `smart_calculator.py`
2. شغليه في أي محرر بايثون
3. اكتبي العدد الأول مثلاً `10`
4. اكتبي العدد الثاني مثلاً `5`
5. بتشوفين الجمع والطرح والضرب والقسمة، ومن الأكبر!

### 🧠 وش تعلمت منه؟
- كيف آخذ معلومتين من المستخدم
- العمليات الحسابية الأربعة
- أهم شي: `if / else` - كيف أخلي البرنامج يقرر لحاله!

هذا هو أساس الذكاء الاصطناعي، البرنامج اللي يقرر!
